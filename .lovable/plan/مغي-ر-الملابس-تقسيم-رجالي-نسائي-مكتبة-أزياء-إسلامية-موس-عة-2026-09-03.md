# مغيّر الملابس: تقسيم رجالي/نسائي + مكتبة أزياء إسلامية موسّعة

## الفكرة
ركنا **تراثي** و**رسمي** يصيران بداخلهما تبويب صنف: **رجالي** و**نسائي**، مع مكتبة نسائية جديدة محتشمة (إسلامية) مبنية على بحث في الأزياء السودانية والمغاربية والخليجية.

```text
[كاجوال] [تراثي] [رسمي] [رياضي وبجامات]
             |        |
        [رجالي|نسائي] [رجالي|نسائي]
```

## 1) واجهة الصنف (Gender)
- شريط تبويب صغير يظهر فقط داخل «تراثي» و«رسمي»: رجالي / نسائي.
- تغيير الصنف يعيد ضبط الخيار الافتراضي للتصميم.
- عند اختيار «نسائي» تتبدل قائمة غطاء الرأس تلقائياً إلى: بدون / حجاب / طرحة / خمار / نقاب / طرحة سودانية، بدل الطاقية والطربوش.

## 2) تراثي — نسائي (بحث ثقافي)
سوداني: الثوب السوداني (قرمصيص، ثوب شيفون مطرز، ثوب زفة العروس بألوان زاهية)، ثوب توب أبيض تقليدي.
مغاربي: قفطان مغربي مطرز بالسفيفة، تكشيطة بحزام، جلابة مغربية بقُب، جبادور، ملحفة موريتانية، جبة تونسية، كراكو جزائري.
خليجي/شرقي: عباية خليجية سوداء مطرزة، عباية كِمّ فراشة، عباية ملوّنة كلوش، ثوب النشل، درّاعة إماراتية، جلابية مصرية فلاحي، ثوب فلسطيني مطرّز بالتطريز الكنعاني.

## 3) رسمي — نسائي (بحث في الأزياء الإسلامية)
- عباية عمل رسمية سادة، عباية بليزر (Abaya-blazer)، طقم بليزر وبنطلون واسع محتشم، بدلة نسائية بتنورة طويلة (ماكسي)، بدلة كحلي مع تنورة بليسيه، جلباب مكتبي طويل.
- فساتين: فستان ماكسي محتشم بأكمام طويلة، فستان سهرة إسلامي مطرّز بحجاب متناسق، فستان زفاف محتشم بأكمام وطرحة، قفطان سهرة فاخر بحزام، فستان شيفون بطبقات.
- كل الخيارات مقيّدة بضوابط: أكمام طويلة، طول كامل، قصّة فضفاضة غير واصفة، رقبة مغلقة.

## 4) المنطق الخلفي
- إضافة أوصاف Prompt دقيقة لكل تصميم جديد في `OUTFIT_VARIANTS` داخل دالة `photo-edit`.
- إضافة قاعدة احتشام عامة تُحقَن تلقائياً عند `gender = "female"`: تغطية كاملة، عدم كشف الشعر إن اختير غطاء رأس، الحفاظ على الوجه والملامح والوضعية كما هي.
- الحفاظ على المنطق الحالي: منع الجزمة/العجاز في الصور النصفية، معاينة قبل القبول، وخصم الرصيد عند القبول فقط.

- شريط التقدّم يبقى: «الخال شغال.. بظبط في الملابس».
